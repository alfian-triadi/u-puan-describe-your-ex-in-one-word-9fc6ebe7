## The word

**unsubscribe**

An ex is a subscription you finally cancelled. One real word, instantly readable as a verdict on a former partner: you opted out — no renewal, no re-engagement emails, no "we miss you" discount. The joke lands with the word itself.

## How it works

`main.ts` writes the word to `/output/entry.txt` (11 characters, well within the 111-character cap), then verifies the file is byte-identical to what was written.

```sh
node main.ts
```
